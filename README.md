## Introduction

Integrating artificial intelligence and terminal-native tools like Claude Code into red team operations fundamentally enhances campaign planning, payload validation, command generation, and post-exploitation analysis. Hosted on [Learn SecByte](https://learn.secbyte.org/), this advanced AI offensive security and red team automation collection provides comprehensive, practical training to execute and defend against end-to-end cyber operations.

From leveraging AI for full-lifecycle attack planning, crafting tailored initial access payloads, and generating context-aware CLI commands to conducting Claude Code terminal red team assessments, analyzing local privilege escalation vectors, triaging complex exploit payloads, probing prompt injection and agent vulnerabilities, and managing ethical responsible disclosure, these exercises prepare operators for advanced security challenges.

## How to Use the Labs

1. Select a challenge link from the index or category sections above.
2. Read the scenario directives and target parameters on [Learn SecByte](https://learn.secbyte.org/).
3. Deploy security toolsets (Claude Code CLI, Python, Metasploit, Burp Suite, Atomic Red Team, Caldera, LinPEAS/WinPEAS) inside an isolated workstation.
4. Synthesize campaign attack plans, generate CLI payloads, execute terminal red team tasks, analyze privilege escalation paths, and draft vulnerability disclosures.
